LOST KINGDOM - ANDROID EDITION

This project is a touch-screen Kivy version of the Lost Kingdom text RPG.

Build on Windows with WSL/Ubuntu:
1. wsl --install
2. sudo apt update
3. sudo apt install -y python3-pip git zip unzip openjdk-17-jdk
4. pip3 install --user buildozer
5. cd to this project folder
6. buildozer -v android debug

The APK will appear in the bin/ folder.
